## 团队与职责

1. 刘煜飞

负责模块：前端开发与用户界面设计

核心任务：

- 设计并实现系统前端页面（包括登录页、匹配结果展示页、用户信息编辑页等）；
- 保证前端页面的交互性与响应式布局，适配不同设备；
- 与后端开发对接，实现前端与后端的数据交互；
- 优化前端加载速度与用户体验。

交付物：前端代码（HTML/CSS/JavaScript 等）、页面原型设计图、前端与后端交互文档。

2. 刘佳城

负责模块：后端逻辑开发与 API 设计

核心任务：

- 设计系统后端架构，搭建服务器环境；
- 开发核心业务逻辑（如用户认证、匹配算法调用、数据校验等）；
- 设计并实现供前端调用的 API 接口，编写 API 文档；
- 处理后端异常与性能优化；
- 实现 AI 对话/助手接口并负责 AI 服务调用与降级策略（LLM 接入、本地规则降级）。

交付物：后端代码（TypeScript语言实现）、API 接口文档、服务器配置说明。

3. 刘城宇

负责模块：数据库设计与数据管理

核心任务：

- 设计数据库表结构（包括用户表、项目表、匹配记录表等），保证数据关系合理性；
- 实现数据库的创建、查询、更新、删除等操作；
- 优化数据库查询性能，处理数据备份与恢复；
- 与后端开发协作，提供数据访问支持。

交付物：数据库设计文档（ER 图）、数据库脚本、数据备份策略文档。

4. 熊昱浩

负责模块：测试与文档编写

核心任务：

- 制定测试计划，编写测试用例（包括单元测试、集成测试、功能测试）；
- 执行测试并记录 BUG，跟踪修复进度；
- 编写项目整体文档（如需求说明书、用户手册、部署指南）；
- 协助团队进行代码评审，确保代码规范。

交付物：测试用例文档、BUG 跟踪表、项目需求说明书、用户手册、部署指南。
